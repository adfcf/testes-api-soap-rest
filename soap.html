Detalhes de API

Essa simples demonstração de cálculo utiliza a API pública e gratuita do TestingAPIs. A API utiliza modelo SOAP e está documentada nesta página.

De certa forma, o modelo SOAP é mais "burocrático" que o REST; as operações disponíveis precisam estar precisamente especificadas em WSDL, e tanto as requisições tanto as respostas precisam seguir esse formato de acordo com a especificação. Em comparação, essa implementação precisou de mais preparo para se comunicar com a API SOAP.
